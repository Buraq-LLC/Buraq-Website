Pi Module

The Buraq AI Raspberry Pi module brings powerful edge AI processing to field operations. Designed for rugged environments, this compact unit processes visual intelligence locally, reducing latency and enabling real-time decision-making in areas with limited connectivity.

Step 1: Hardware Setup
  • Ensure you have a Raspberry Pi 4 Model B (4GB or 8GB RAM recommended) with the official Buraq AI HAT attached.
  • Connect power supply (5V, 3A minimum) and ensure all connections are secure.
  • Insert a microSD card (32GB+) with the pre-configured Buraq AI OS image.
  • Connect camera module to the CSI port and verify camera detection with vcgencmd get_camera.

Step 2: Initial Configuration
  • Power on the device and wait for the initial boot sequence (approximately 2 minutes).
  • Connect to the device via SSH using the default credentials provided in your deployment package.
  • Run the setup wizard: sudo buraq-setup and follow the on-screen prompts.
  • Configure network settings (WiFi or Ethernet) and set your preferred timezone and locale.

Step 3: Connect to Buraq Platform
  • Log in to your Buraq AI dashboard at dashboard.buraq-ai.com and navigate to the "Devices" section.
  • Click "Add New Device" and select "Raspberry Pi Module" from the device type dropdown.
  • Generate a secure device token by clicking "Generate Token" - this token will be displayed only once.
  • On your Pi module, run sudo buraq-register --token YOUR_TOKEN to authenticate the device with the platform.
  • Verify the connection status in the dashboard - you should see a green indicator once the device is successfully registered.

Step 4: Configure AI Models
  • From the dashboard, select your registered device and navigate to the "AI Models" tab.
  • Choose which detection models to deploy based on your operational needs (person detection, vehicle classification, threat identification).
  • Download the selected models to the device by clicking "Deploy Models" - this may take 5-10 minutes depending on connection speed.
  • Configure detection thresholds and alert parameters in the "Model Settings" section.
  • Test the model deployment by running buraq-test-inference on the Pi module.

Step 5: Deploy and Monitor
  • Mount the Pi module in your chosen location using the weatherproof enclosure provided.
  • Ensure the camera has an unobstructed view of the area you need to monitor.
  • Start the inference service: sudo systemctl start buraq-inference.
  • Enable automatic startup on boot: sudo systemctl enable buraq-inference.
  • Monitor real-time detections and system health through the Buraq AI dashboard.
  • Set up automated alerts for critical events in the "Notifications" section of your dashboard.

Step 6: Maintenance and Updates
  • The Pi module will automatically check for software updates daily.
  • To manually trigger an update, run sudo buraq-update on the device.
  • Monitor system performance metrics (CPU, memory, temperature) through the dashboard.
  • Clean the camera lens regularly to maintain optimal detection accuracy.
  • Review detection logs periodically: journalctl -u buraq-inference -f.

Step 7: Troubleshooting
  • If the device doesn't appear in the dashboard, verify network connectivity with ping 8.8.8.8.
  • Check service status with sudo systemctl status buraq-inference to identify any errors.
  • Review system logs for detailed error messages: sudo journalctl -xe.
  • Consult the Buraq AI documentation at docs.buraq-ai.com for detailed troubleshooting guides.
  • For persistent issues, contact our support team through the dashboard's help section or email support@buraq-ai.com.
  • Include your device ID and relevant log snippets when contacting support for faster resolution.
